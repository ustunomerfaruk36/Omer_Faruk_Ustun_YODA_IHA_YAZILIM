## 1. Veri Tipleri 

Python'da her değerin bir veri tipi vardır. Değişken tanımlarken tipi önceden belirtmeye gerek yoktur; Python bunu otomatik olarak algılar.

### Temel Veri Tipleri ve Özellikleri

* **int :** Pozitif veya negatif tam sayıları temsil eder (`10`, `-5`, `0`).
* **float:** Kesirli ve ondalıklı sayıları temsil eder (`3.14`,).
* **str:** Tek (`' '`) veya çift (`" "`) tırnak içinde yazılan metinlerdir. Değiştirilemez yapıdadırlar.
* **bool:** Yalnızca iki değer alır: `True` veya `False`. Karar yapılarında sıkça kullanılır.
* **list:** Birden fazla veriyi sıralı bir şekilde tutan, sonradan değiştirilebilir (*mutable*) koleksiyonlardır ( 1, "elma"]`).
* **tuple:** Listelere benzer ancak oluşturulduktan sonra elemanları değiştirilemez (`(10, 20, 30)`).
* **`dict` (Sözlük):** Verileri `anahtar: değer` (*key: value*) çiftleri halinde tutar (`{"ad": "Ahmet", "yas": 25}`).
* **set:** Sırasızdır ve her elemandan yalnızca bir tane barındırır (`{1, 2, 3}`).

### Kod Örneği

```python
sayi = 42                  # int
pi = 3.14                  # float
mesaj = "python"           # str
aktif_mi = true            # bool

diller = ["Python","C++"]                   # list
koordinat = (41.0082, 28.9784)              # tuple
ogrenci = {"ad": "Zeynep", "not": 95}       # dict
benzersiz_sayilar = {1, 2, 2, 3}            # set -> {1, 2, 3}

print(type(mesaj))      # <class 'str'>
print(ogrenci["ad"])    #  Zeynep
```

## 2. Koşullu İfadeler (Conditionals: `if-elif-else`)

Programların belirli şartlara göre farklı yollar izlemesini (karar vermesini) sağlayan yapılardır. Python'da kod blokları girintileme (*indentation* - genellikle 4 boşluk) ile belirlenir.

* **`if`:** İlk koşulu kontrol eder. Koşul `True` ise altındaki blok çalışır.
* **`elif`:** Önceki koşul(lar) `False` ise yeni bir koşul kontrol etmek için kullanılır.
* **`else`:** Yukarıdaki koşulların hiçbiri sağlanmazsa çalışacak varsayılan bloktur.

### Kod Örneği

```python
sinav_notu = 78

if sinav_notu >= 85:
    print("Harf Notu: Pekiyi")
elif sinav_notu >= 70:
    print("Harf Notu: İyi")
elif sinav_notu >= 50:
    print("Harf Notu: Geçer")
else:
    print("Harf Notu: Kaldı")

# Çıktı: Harf Notu: İyi
```

## 3. Döngüler (Loops: `for`, `while`)

Tekrar eden işlemleri kısa ve verimli bir şekilde gerçekleştirmek için döngüler kullanılır.

### `for` Döngüsü
Bir liste, metin veya sayı aralığı (`range`) gibi yinelenebilir  bir nesnenin tüm elemanları üzerinde sırayla gezinmek için kullanılır.

### `while` Döngüsü
Belirtilen bir koşul `True` olduğu sürece çalışmaya devam eden döngüdür. Sonsuz döngüye girmemek için koşulu değiştirecek bir mekanizma kurulmalıdır.

### Döngü Kontrol İfadeleri
* **`break`:** Döngüyü tamamen sonlandırır ve dışına çıkar.
* **`continue`:** Mevcut adımı atlar ve döngünün bir sonraki adımına geçer.

### Kod Örneği

```python
meyveler = ["Elma", "Armut", "Muz"]
for meyve in meyveler:
    print(f"Meyve: {meyve}")


for i in range(1, 6):
    if i == 3:
        continue  
    print(i)      # Çıktı: 1, 2, 4, 5

# while döngüsü örneği
sayac = 3
while sayac > 0:
    print(f"Geri sayım: {sayac}")
    sayac -= 1
print("Başladı")
```

## 4. Fonksiyonlar

Belirli bir görevi yerine getirmek üzere yazılan, tekrar kullanılabilir kod bloklarıdır. Kod tekrarını önler ve programı modüler hale getirir.

* **`def`:** Fonksiyon tanımlamak için kullanılan anahtar kelimedir.
* **Parametreler:** Fonksiyonun dışarıdan aldığı verilerdir.
* **`return`:** Fonksiyonun ürettiği sonucu çağrıldığı yere geri döndürür.

### Kod Örneği

```python

def alan_hesapla(genislik, yukseklik=10):
    alan = genislik * yukseklik
    return alan

# Fonksiyonu çağırma
sonuc1 = alan_hesapla(5, 8)

print(f"Alan 1: {sonuc1}")  # Alan 1: 40
```

## 5. Sınıflar ve Nesne Yönelimli Programlama 

Sınıflar (`class`), nesne oluşturmak için kullanılan şablonlardır (*blueprint*). Gerçek dünyadaki varlıkları veya kavramları özellikleriyle (**attributes**) ve davranışlarıyla (**methods**) birlikte modellememizi sağlar.

* **`class`:** Sınıf tanımlamak için kullanılır. Sınıf isimleri genellikle BüyükHarfle (PascalCase) başlar.
* **`__init__` (Yapıcı Metot):** Sınıftan yeni bir nesne türetildiğinde otomatik çalışan başlangıç metodudur.
* **`self`:** Oluşturulan nesnenin kendisini temsil eder ve sınıf içindeki değişkenlere/metotlara erişimi sağlar.


```python
# 1.
class Kopek:
    # Köpek oluşturulurken adını ve yaşını belirleriz
    def __init__(self, ad, yas):
        self.ad = ad
        self.yas = yas

    # Köpeğin yapabileceği basit bir eylem (Metot)
    def havla(self):
        print(f"{self.ad}: Hav hav!")


kopek1 = Kopek("Karabaş", 3)
kopek2 = Kopek("Boncuk", 1)
print(kopek1.ad)       # Karabaş
print(kopek2.yas)      # 1


kopek1.havla()         #  Karabaş: Hav hav!
kopek2.havla()         #  Boncuk: Hav hav!
```
